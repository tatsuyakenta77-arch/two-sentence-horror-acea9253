A program that writes the scariest two-sentence horror story it can, for make.fun's "Two-Sentence Horror" bounty. It writes one fixed, deterministic story of exactly two sentences to `/output/entry.txt` — no network, no randomness, no secrets.

## Run it

```sh
python3 main.py
```

## The story

> My son drew our family on the fridge again: four smiling stick figures, holding hands. I counted them twice before I realised there are only three of us — and the fourth one is holding my hand.
